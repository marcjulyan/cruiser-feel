# Shift feel

Three big buttons (GOOD / BAD / NOISE + UNDO) for rating gearbox shifts while driving.

- Works offline: each tap is saved on the phone with the phone's clock, then sent when there is signal.
- This page holds no data. Taps go to a private channel whose key only the owner's phone and logger know
  (it arrives in the setup link, never stored here).
- The car's logger collects the taps and lines them up with the drive data by time.
